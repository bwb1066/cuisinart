The metadata block really applies to the page it's on, so this sample uses only harmless keys (title, description, image). The other keys are listed as plain text: a second table would be read as a second block.

Metadata

Page-level metadata for this page. Put one metadata block at the very end of the page. The first column is the key and the second is the value. To set a key for many pages at once, use the bulk /metadata sheet with a URL pattern; a value here on the page overrides the sheet.

Keys this site reads

  • title: the browser tab and search result title.
  • description: the search and social description.
  • image: the social share image (og:image).
  • header-path / footer-path: the fragment to load as the nav. Defaults are /fragments/nav/header and /fragments/nav/footer.
  • header / footer: the block name. Use off to hide it. This is NOT a path.
  • template: loads a page template's styles and script.
  • breadcrumbs: the breadcrumb fragment path.
  • favicon: the favicon base name in /img/favicons/ (default favicon).
